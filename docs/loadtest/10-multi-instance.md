# 단일 vs 멀티 인스턴스 비교 테스트

## 테스트 개요
- **목적**: 수평 확장(1대 → 2대) 효과 정량 측정 — 선형 확장성 검증
- **테스트 순서**: 단일 인스턴스 → 2대 인스턴스, 동일 시나리오 반복
- **실행 시각**: (테스트 실행 후 기입)
- **총 소요 시간**: ~25분 (테스트 + ASG 전환 대기)

## 테스트 환경

### 환경 A: 단일 인스턴스
| 항목 | 값 |
|------|-----|
| BE 인스턴스 | 1대 × t3.medium Spot |
| HikariCP | max=30 (단일 인스턴스) |
| 총 커넥션 풀 | 30 |

### 환경 B: 멀티 인스턴스
| 항목 | 값 |
|------|-----|
| BE 인스턴스 | 2대 × t3.medium Spot |
| HikariCP | max=30 × 2 |
| 총 커넥션 풀 | 60 |

### 공통
- RDS: db.t3.medium Primary + db.t3.small Replica
- 데이터: 600 users, 1,500+ posts

## 테스트 절차
```
1. BE ASG desired=1로 축소, 안정화 대기 (3분)
2. 단일 인스턴스로 ccu_test.js 실행
3. 단일 인스턴스로 stress_test.js 실행
4. BE ASG desired=2로 복원, 안정화 대기 (3분)
5. 2대 인스턴스로 ccu_test.js 실행 (Phase 5.2 결과 재사용 가능)
6. 2대 인스턴스로 stress_test.js 실행 (Phase 5.3 결과 재사용 가능)
```
