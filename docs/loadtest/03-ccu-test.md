# CCU (동시접속자) 단계별 부하 테스트

## 테스트 개요
- **목적**: 동시접속 한계점 식별 — 10→50→100→200 CCU 단계별 성능 변화 측정
- **스크립트**: `scripts/k6/ccu_test.js`
- **실행 시각**: (테스트 실행 후 기입)
- **소요 시간**: ~7분

## 테스트 환경
- BE 인스턴스: 2대 × t3.medium Spot (HikariCP max=30, JVM -Xms1g -Xmx1500m)
- RDS: db.t3.medium Primary + db.t3.small Replica
- 데이터: 600 users, 1,500 posts, ~20,000 comments

## 시나리오 설정
| 시나리오 | Executor | VUs | Stages | 비고 |
|----------|----------|-----|--------|------|
| ccu_stages | ramping-vus | 0→10→50→100→200→0 | 각 단계 30s ramp + 1m hold | 70% 읽기 / 30% 쓰기 |

### 단계별 VU 구성
| Stage | 목표 VUs | Ramp 시간 | Hold 시간 |
|-------|----------|-----------|-----------|
| 1 | 10 | 30s | 1m |
| 2 | 50 | 30s | 1m |
| 3 | 100 | 30s | 1m |
| 4 | 200 | 30s | 1m |
| Ramp-down | 0 | 30s | — |

### 시나리오 상세
- 70% 비로그인 사용자: 게시글 목록 → 상세 → 댓글 조회
- 30% 로그인 사용자: 위 + 좋아요 + 10% 확률 댓글 작성
